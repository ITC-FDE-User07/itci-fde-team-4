Catalogue

Pricing

Stock event

POST /v1/stock/events

Requires warehouse or POS role. Repeats use the same event ID only when manually replaying.

Price override

POST /v1/overrides

Requires POS role. Creates an audit record.

Audit log

GET /v1/audit/overrides

Fetch recorded override actors, reasons and request IDs.

Integration outbox

GET /v1/events

Requires ERP role. Shows pending and published event records.

Checkout

POST /v1/checkout

Changes stock and calls the payment partner. Use only with local test services.
